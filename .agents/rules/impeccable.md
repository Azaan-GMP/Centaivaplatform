# Rule: Impeccable (Design Language & Frontend Polish)

1. **Stunning Visual Aesthetics**: Every UI element must look premium, polished, and purposeful. Avoid plain/generic designs.
2. **Dual Theme Perfection**: Ensure both **Light Mode** and **Dark Mode** have 100% contrast, crystal-clear typography, and harmonious color tokens.
3. **No Muddy or Generic Colors**: Use curated cyber-navy/obsidian + electric cyan/emerald for Dark Mode, and crisp white/slate + sky blue for Light Mode. No unintended purple hues.
4. **Interactive Polish**: Every button, link, and card must feature smooth transitions, clear hover/focus/active feedback, and pleasant micro-animations.
5. **Clean Modals & Overlays**: Modals must overlay the entire screen (z-index 9999) with frosted glass backdrop blur without being clipped by parent stacking contexts.
