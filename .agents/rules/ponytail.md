# Rule: Ponytail (Lazy Senior Dev)

1. **YAGNI (You Ain't Gonna Need It)**: Do not write code for hypothetical features. Build only what is needed now.
2. **Reuse Existing Code**: Always check existing services, helpers, and components in this project before creating new ones.
3. **Standard Library & Native First**: Prefer built-in Angular/RxJS/DOM capabilities over installing new packages or creating excessive boilerplate.
4. **Simplicity Over Cleverness**: The cleanest solution is the simplest one that correctly solves the user's problem.
5. **No Compromise on Quality**: Simple code must still be strongly typed, secure, and error-handled.
