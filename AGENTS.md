# Project Guidelines & Agent Instructions

This repository is governed by two complementary standards:

## 1. 🦹‍♂️ Ponytail ("Lazy Senior Dev") Philosophy
- **YAGNI**: The best code is the code you never wrote. Never over-engineer.
- **Ladder of Simplicity**: Before writing new code, check if it can be solved by existing code, standard library, native platform features, or a clean one-liner.
- **Direct & Maintainable**: Keep implementations simple, readable, and robust with strong typing and error handling.

## 2. 💎 Impeccable ("Design Language & UI Polish") Philosophy
- **Executive SaaS Aesthetics**: Every screen, card, modal, and badge must meet world-class design standards (clean Stripe / Linear / Apple SaaS feel).
- **Flawless Light & Dark Modes**: High-contrast typography (`#0F172A` in light, `#F8FAFC` in dark), curated cyber-navy/cyan/emerald accents, and zero muddy purple tones.
- **Micro-Interactions & UX**: Smooth transitions, frosted glass backdrops, responsive hover states, and clear interactive feedback.
