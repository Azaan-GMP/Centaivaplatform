========================================================================
SESSION / SWITCH MODEL
========================================================================

Centaiva Platform Control token:
- tenantless for Platform Owner
- do not use it for WorkWell company data
- do not call tenant-specific session policy with this token

Tenant-bound WORKWELL_FINANCE session:
- 10 hours / 600 minutes where the selected tenant authentication policy is configured

WorkWell tenant switch:
1. Login with workwell-finance-web
2. GET /api/v1/me/tenants?applicationKey=WORKWELL_FINANCE
3. POST /api/v1/me/select-tenant for initial selection
4. Exchange selectionCode at /connect/token
5. Use final tenant-bound WorkWell token
6. POST /api/v1/me/switch-tenant to change WorkWell tenant
7. Exchange the new selectionCode
8. Replace old WorkWell token

Do not change CompId inside a final token.

MedPure follows the same Central tenant-selection pattern using
WORKWELL_FINANCE, workwell-finance-web and the workwell.finance scope.
