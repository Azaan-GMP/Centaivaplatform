# AI Developer Instructions

Before making any changes, analyze the entire project structure, architecture, coding patterns, reusable components, services, utilities, guards, interceptors, shared modules, and existing implementations.

This repository is the **master Angular GMP template**. Treat it as the source of truth.

## Rules

* Strictly follow the existing project structure.
* Do **not** create a new architecture or reorganize folders.
* Reuse existing components, services, utilities, and shared modules whenever possible.
* Follow the project's existing coding style, naming conventions, and Angular best practices.
* Keep all code modular, scalable, reusable, and production-ready.
* Avoid duplicate implementations.
* Before adding new code, check whether similar functionality already exists and extend or reuse it.
* If existing issues or bugs are found, fix them using the current architecture instead of creating alternative solutions.
* Modify only the files required for the requested task.
* Do not remove or refactor core project structure unless explicitly instructed.

## New Project Setup

When this template is used for a new project (e.g., **MedPure**), automatically:

* Replace the project name, branding, and application metadata.
* Preserve the complete folder structure and architecture.
* Add only project-specific business logic and features.

## For every request

First understand the existing implementation, then implement the requested functionality while preserving the architecture and following these instructions without exception.
